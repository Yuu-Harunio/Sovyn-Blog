用 Cloudflare Workers 免费托管个人博客的完整实践

大纲
1. 为什么选 Workers 2. 配置静态资源 2.1 wrangler.jsonc 2.2 目录结构 3. 绑定域名 4. 自动部署

1. 为什么选 Workers

Cloudflare Workers 的静态资源托管对个人博客来说绰绰有余：免费额度 100,000 请求/天，无需绑定付款方式，全球 CDN 直出。相关概念可以参考 Cloudflare 免费额度详解这篇笔记（这是 [[双向链接]] 的效果），而 D1 数据库选型 是一篇未发布的笔记（降级为虚线纯文本，悬停有提示）。

静态站点 + CDN 直出 = 响应速度的上限就是物理极限。没有渲染、没有查询、没有登录。
ℹ️

2. 配置静态资源

核心就一个配置文件，把构建产物 dist/ 指给 Worker：

wrangler.jsonc 
{
  "name": "my-blog",
  "compatibility_date": "2026-08-28",
  "assets": {
    "directory": "./dist",      // 构建产物目录
    "not_found_handling": "404-page" // 找不到时返回 404 页
  }
}

2.1 wrangler.jsonc

不需要写任何 Worker 代码，纯静态资源模式下 Workers 直接当文件服务器用。点击代码块右上角的 复制 按钮可以体验一键复制功能。

bash 
# 构建并部署，两条命令上线
npm run build
npx wrangler deploy

2.2 目录结构

目录用途
content/Obsidian 拷入的 Markdown 原文
content/assets/笔记引用的图片附件
templates/手写 HTML 模板
dist/构建产物（部署这个）
💡
提示 · [!tip]

frontmatter 写上 publish: true 的笔记才会被构建为公开页面，其余静默忽略。

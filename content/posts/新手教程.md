# 🧠 Obsidian 新手指南 · 精简起步版

> 本文档专为第一次打开 Obsidian 的你准备。  
> 目标是：**10 分钟完成基础设置，立刻开始写笔记，不纠结、不焦虑**。

> **开篇摘要**：本指南面向第一次打开 Obsidian 的用户，目标是 10 分钟完成核心设置：必开插件、社区插件、文件夹结构、日常写作操作与快捷键，并建立"用双向链接连接知识"的基本认知。

---

## 1. 第一次启动

- 从 [obsidian.md](https://obsidian.md) 下载安装。
- 打开后点击「创建新知识库」（Create new vault），选择一个**本地文件夹**存放所有笔记。
- 所有笔记都是 `.md` 文件，即使未来不用 Obsidian，也能用任何文本编辑器打开。

---

## 2. 必开的核心插件（内置）

进入「设置 → 核心插件」，建议**全部开启**，但下面几个尤其重要：

| 插件 | 作用 |
|------|------|
| **每日笔记** | 每天自动生成一篇日记，记录日常碎片 |
| **模板** | 配合 Templater 或内置模板，快速生成固定格式 |
| **反向链接** | 显示哪些笔记引用了当前笔记，是知识串联的关键 |
| **关系图谱** | 可视化你的笔记网络，越用越震撼 |
| **画布** | 白板式脑图，适合构思复杂主题 |
| **大纲** | 显示标题层级，快速跳转 |

---

## 3. 社区插件（按需安装，新手先装 3～5 个）

关闭「设置 → 社区插件 → 安全模式」，然后浏览社区插件市场，推荐从以下选择：

- **Calendar** – 在侧边栏显示日历，方便点选每日笔记
- **Dataview** – 用类 SQL 语法查询笔记元数据，构建动态列表（进阶，但值得学）
- **Templater** – 更强大的模板工具，支持日期变量、脚本等
- **Tasks** – 强大的任务管理，可汇总所有未完成待办
- **Excalidraw** – 手绘风格绘图，适合画流程图、思维导图

> 提示：**插件不是越多越好**，先用熟 3 个，再慢慢添加。

---

## 4. 推荐的文件夹结构（简单、够用）

在知识库根目录下建立以下文件夹（也可按自己习惯调整）：

```
📁 Inbox/       —— 临时想法、快速捕获
📁 Journal/     —— 每日笔记（建议按年/月分层）
📁 Projects/    —— 具体项目笔记
📁 Areas/       —— 长期关注领域（如健康、编程、阅读）
📁 Resources/   —— 参考资料、摘录
📁 Archives/    —— 归档旧笔记
📁 Templates/   —— 存放模板文件
```

> 文件夹只是分类辅助，**真正连接知识的是双向链接**，不用过度整理。

---

## 5. 日常写作核心操作

### 创建新笔记
- 快捷键 `Ctrl/Cmd + N`
- 或在任意笔记中用 `[[新笔记名称]]` 创建链接，点击后自动生成新笔记。

### 常用 Markdown 语法
| 效果 | 语法 |
|------|------|
| 标题 | `# 一级` 到 `###### 六级` |
| 加粗 | `**加粗**` |
| 斜体 | `*斜体*` |
| 列表 | `- 无序` / `1. 有序` |
| 待办 | `- [ ] 未完成` / `- [x] 已完成` |
| 代码块 | ` ```语言 ``` ` |
| 引用 | `> 引用内容` |
| 内部链接 | `[[笔记名]]` 或 `[[笔记名\|显示文字]]` |
| 外部链接 | `[文字](URL)` |
| 图片 | `![[图片.png]]` |

### 每日笔记流程
1. 按 `Ctrl/Cmd + D` 快速打开今日日记。
2. 在日记中记录当天任务、想法、会议纪要。
3. 用 `[[项目名]]` 关联到具体项目笔记。

## 7. 备份与同步（选看）

- **本地备份**：直接复制整个知识库文件夹到 U 盘或外置硬盘。
- **云同步**：推荐 OneDrive、iCloud、Dropbox（注意移动端同步需额外设置）。
- **Git 版本管理**（进阶）：适合有编程习惯的用户，可保留所有历史版本。

---

## 8. 常见问题速查

| 问题 | 解决办法 |
|------|----------|
| 插件安装失败 | 检查网络，或手动从 GitHub 下载安装包放入 `.obsidian/plugins/` |
| 笔记打不开 | 确认文件后缀是 `.md`，且未被其他程序锁定 |
| 图谱太乱 | 使用「图谱」筛选器，只显示特定标签或路径 |
| 移动端同步慢 | 使用 iCloud 或 Obsidian Sync 官方服务 |
| 搜索不到内容 | 检查是否开启了「设置 → 文件与链接 → 排除文件」中的过滤项 |

---

## 9. 最后的建议

- **不要追求完美的文件夹分类**，随着笔记增多，结构会自然演化。
- **坚持每天写一点**，哪怕只有三行。
- **多用 `[[双向链接]]`**，让知识从孤立走向网络。
- **定期回顾**：每周花 10 分钟浏览反向链接和未完成的任务。

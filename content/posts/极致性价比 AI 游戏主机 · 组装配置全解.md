## 一、CPU：AMD Ryzen 5 7500F

### 1.1 选了什么

**AMD Ryzen 5 7500F**（6核12线程，Zen4架构，65W TDP，无核显），搭配微星B650M迫击炮以"板U套装"形式购买，套装价约 ¥1,530–1,700。

### 1.2 为什么选它

| 理由            | 说明                                                         |
| --------------- | ------------------------------------------------------------ |
| **AM5平台寿命** | AMD官方承诺AM5插座至少支持到2027年以后，覆盖Ryzen 7000/8000/9000三代。未来换CPU不用换主板，这是"多年适配"的核心 |
| **全大核架构**  | 6个核心全部是高性能大核，没有Intel大小核调度问题。AI推理预处理、游戏单线程都走大核，不踩坑 |
| **功耗极低**    | 65W TDP，百元风冷就能压住，不需要为散热多花钱                |
| **性价比**      | 同价位Intel i5-13400F/14400F是LGA1700末代平台，无法升级；7500F是AM5入门，未来路更长 |
| **AI场景够用**  | 本地AI生成速度99%取决于显卡显存带宽，CPU只负责tokenize和采样。7500F完全不是瓶颈 |

### 1.3 CPU选购核心参数

| 参数              | 含义                            | 怎么看                                         |
| ----------------- | ------------------------------- | ---------------------------------------------- |
| **架构/制程**     | 决定IPC（每时钟指令数）和能效比 | Zen4（TSMC 5nm）> Zen3 > Intel 12代（Intel 7） |
| **核心数/线程数** | 多任务并行能力                  | 游戏6核够，AI/生产力8核起步，12核以上边际递减  |
| **单核性能**      | 游戏帧数的关键指标              | 看Cinebench R23单核分数，>1800为优秀           |
| **TDP/功耗**      | 决定散热器和电源需求            | 65W=省心，105W=需要好散热，170W=需要水冷       |
| **平台/插座**     | 决定未来能否升级CPU             | AM5（AMD）寿命长；LGA1700（Intel）已到末期     |
| **有无核显**      | 是否需要独显才能亮机            | 7500F无核显（"F"后缀），必须配独显；7600有核显 |
| **内存支持**      | 平台兼容的内存类型              | AM5仅支持DDR5；LGA1700支持DDR4/DDR5            |

### 1.4 AMD vs Intel 怎么选（补充知识）

| 维度     | AMD Ryzen                   | Intel Core                     |
| -------- | --------------------------- | ------------------------------ |
| 架构     | Chiplet小芯片 + 统一大核    | 大小核混合（P-Core + E-Core）  |
| 制程     | TSMC 4nm/5nm（台积电）      | Intel 7/4（自家工厂，追赶中）  |
| 平台寿命 | AM5支持到2027+，跨3代       | LGA1700已死，LGA1851刚起步     |
| 内存     | DDR5-6000甜点，EXPO一键超频 | DDR5兼容性好但高频稳定性稍差   |
| 核显     | RDNA3核显≈入门独显          | UHD/Iris Xe≈亮机卡             |
| AI指令集 | AVX-512原生支持             | 消费级AVX-512被阉割            |
| 市场份额 | DIY市场≈48%，持续增长       | 企业/OEM市场仍占优（历史惯性） |

> **结论**：个人装机选AMD AM5，企业采购/品牌整机惯性选Intel。两者在x86软件生态上完全兼容，不存在"某软件只支持Intel"的问题。

## 二、主板：微星 B650M 迫击炮 WiFi

### 2.1 选了什么

**微星 MAG B650M MORTAR WiFi（迫击炮）**，M-ATX板型，B650芯片组，12+2+1相供电，双M.2插槽，4条DDR5内存槽，支持WiFi 6E。

> 若未来确定装双卡3090，可升级为 **技嘉 B650 AORUS ELITE AX**（ATX大板，PCIe通道更多），价格约 ¥850–950。

### 2.2 为什么选它

| 理由                   | 说明                                                         |
| ---------------------- | ------------------------------------------------------------ |
| **B650芯片组是甜点**   | 支持CPU超频、PCIe 4.0/5.0、USB4可选。比A620（太丐）强，比X670（太贵）省 |
| **12+2+1相供电**       | 7500F只需6相，但未来换R7 9700X（105W）甚至R9（170W）也够用   |
| **4条DIMM槽**          | 先插2条16GB=32GB，未来补2条到64GB，不用换掉旧条              |
| **双M.2插槽**          | 一块系统盘+一块未来加装的AI模型盘                            |
| **WiFi 6E + 2.5G网口** | 无线/有线都覆盖，不用额外买网卡                              |

### 2.3 主板选购核心参数

| 参数             | 含义                                    | 怎么看                                   |
| ---------------- | --------------------------------------- | ---------------------------------------- |
| **芯片组**       | 决定功能上限（超频、USB数量、PCIe通道） | A620<**B650** M-ATX（小板）> ITX（迷你） |
| **M.2插槽数**    | 能装几块NVMe SSD                        | ≥2个（1个PCIe 4.0 x4 + 1个PCIe 3.0/4.0） |
| **内存插槽数**   | 能插几条内存                            | 4条（标准），2条（ITX/丐板，升级受限）   |
| **PCIe x16插槽** | 显卡插槽，双卡需要看间距                | 单卡1条够；双卡需2条且间距≥2槽           |
| **后置I/O**      | USB数量、Type-C、音频、网口             | 后置≥6个USB，至少1个Type-C               |
| **风扇接口**     | 能接几个机箱风扇                        | ≥4个4-pin PWM风扇头                      |
| **WiFi/蓝牙**    | 是否板载无线                            | 有WiFi 6E最好，没有可后加PCIe无线网卡    |

## 三、显卡：二手 NVIDIA RTX 3090 24GB

### 3.1 选了什么

**二手RTX 3090 24GB GDDR6X**，优先选择三风扇非公版（华硕TUF / 微星SUPRIM / 技嘉AORUS Master），带3–6个月店保，价格 ¥3,500–4,500。

### 3.2 为什么选它（整机灵魂）

| 理由                          | 说明                                                         |
| ----------------------------- | ------------------------------------------------------------ |
| **24GB显存 = 未来多年AI门槛** | 2026年NVIDIA没有发布新游戏GPU，新卡（5060/5070）全部卡在12–16GB。想拿24GB，唯一入口就是二手3090 |
| **936 GB/s显存带宽**          | 是4060 Ti（288 GB/s）的3.2倍，是你笔记本3060的3倍+。AI生成速度由带宽决定 |
| **每GB显存成本最低**          | ≈¥170/GB，远低于4060 Ti（≈¥210/GB）和全新5090（≈¥480/GB）    |
| **32B模型全显存加载**         | Gemma4 31B Q4量化约20GB，3090的24GB全装下，实测≈29.6 tok/s   |
| **游戏性能依然在线**          | 2K分辨率下三角洲行动/无畏契约稳定100+ FPS                    |

### 3.3 显存容量对AI的决定性影响

| 模型档位 | 显存需求 | 笔记本3060 6GB | 4060 Ti 16GB | **3090 24GB**   |
| -------- | -------- | -------------- | ------------ | --------------- |
| 7B Q4    | ~5GB     | 勉强           | 轻松         | 100+ tok/s      |
| 14B Q4   | ~9GB     | ❌ 爆显存       | 轻松         | 轻松            |
| 32B Q4   | ~20GB    | ❌              | ❌ 装不下     | ✅ 全加载        |
| 70B Q3   | ~33GB    | ❌              | ❌            | ✅ CPU轻卸载可玩 |

### 3.4 显卡选购核心参数

| 参数           | 含义                        | 怎么看                                      |
| -------------- | --------------------------- | ------------------------------------------- |
| **显存容量**   | 决定能跑多大的AI模型        | 2026年AI门槛：≥16GB起步，24GB舒适，32GB宽裕 |
| **显存带宽**   | 决定AI生成速度（token/s）   | GDDR6X > GDDR6；看GB/s数值，越高越快        |
| **显存类型**   | GDDR6/GDDR6X/GDDR7/HBM      | 影响带宽上限和功耗                          |
| **CUDA核心数** | NVIDIA并行计算单元数量      | 越多AI推理/游戏渲染越快                     |
| **TDP/功耗**   | 决定电源和散热需求          | 3090=350W，需850W+电源                      |
| **接口**       | PCIe 4.0 x16 / PCIe 5.0 x16 | 当前主板都兼容，不是瓶颈                    |
| **物理尺寸**   | 长度×厚度                   | 3090长310–336mm、3槽厚，必须确认机箱兼容    |
| **供电接口**   | 8pin×2/×3 或 12VHPWR        | 3090用传统8pin，需2–3条独立线材             |

## 四、内存：金百达 DDR5-6000 CL36 16G×2（32GB）

### 4.1 选了什么

**金百达 银爵 DDR5-6000 CL36 16GB×2（共32GB）**，国产长鑫颗粒，支持AMD EXPO一键超频。价格约 ¥550–650。

### 4.2 为什么选它

| 理由                       | 说明                                                         |
| -------------------------- | ------------------------------------------------------------ |
| **AM5只支持DDR5**          | 没得选，DDR5带宽是DDR4的1.5–2倍                              |
| **DDR5-6000是AMD甜点频率** | Zen4/Zen5的Infinity Fabric在FCLK 2000MHz（即DDR5-6000）时1:1同步，超过6000收益急剧递减 |
| **CL36够用**               | CL30比CL36快约3–5%，但贵¥100–200，性价比不高                 |
| **16G×2而非8G×4**          | 只占2条槽位，留2条空槽给未来升级64GB                         |
| **国产颗粒性价比**         | 长鑫/金百达比芝奇/海盗船便宜30–40%，稳定性已验证             |

### 4.3 内存选购核心参数

| 参数            | 含义                 | 怎么看                                      |
| --------------- | -------------------- | ------------------------------------------- |
| **代数**        | DDR4/DDR5            | AM5只能DDR5；LGA1700两者兼容                |
| **频率（MHz）** | 数据传输速率         | DDR5-6000是AMD甜点；Intel可跑更高但收益递减 |
| **时序（CL）**  | 延迟，越低越好       | CL30单通道                                  |
| **颗粒**        | 影响超频潜力和稳定性 | 长鑫/海力士A-die > 三星B-die（DDR5时代）    |
| **EXPO/XMP**    | 一键超频配置文件     | AMD选EXPO认证；Intel选XMP认证               |
| **条数规划**    | 预留升级空间         | 4槽主板先插2条，未来补2条                   |

### 4.4 容量对照

| 容量                | 适用场景           | 你的情况       |
| ------------------- | ------------------ | -------------- |
| 16GB (8×2)          | 2024年已不够       | ❌              |
| **32GB (16×2)**     | 游戏+Ollama 7B–14B | ✅ **当前起步** |
| 64GB (16×4 或 32×2) | 32B模型+多任务     | 🔮 未来升级目标 |

## 五、硬盘：致态 TiPlus7100 1TB

### 5.1 选了什么

**致态 TiPlus7100 1TB NVMe SSD**（PCIe 4.0 x4，TLC颗粒，读7000MB/s，写6000MB/s）。价格约 ¥900–1,000。

### 5.2 为什么选它

| 理由              | 说明                                                  |
| ----------------- | ----------------------------------------------------- |
| **PCIe 4.0 x4**   | 主板B650原生支持，读速7000MB/s，游戏加载/模型加载飞快 |
| **TLC颗粒**       | 寿命和速度平衡点；QLC太丐，MLC太贵                    |
| **1TB起步**       | 系统+游戏+2–3个AI模型（每个10–40GB）刚好够            |
| **国产性价比**    | 致态（长江存储）比三星/西数便宜20–30%，品质已验证     |
| **预留第二块M.2** | 主板有双M.2槽，未来SSD降价后加第二块存模型            |

### 5.3 SSD选购核心参数

| 参数                | 含义                             | 怎么看                                             |
| ------------------- | -------------------------------- | -------------------------------------------------- |
| **接口/协议**       | SATA vs NVMe（PCIe 3.0/4.0/5.0） | NVMe PCIe 4.0是当前甜点；PCIe 5.0发热大暂不急      |
| **颗粒类型**        | SLC/MLC/TLC/QLC                  | TLC是性价比之王；QLC寿命短不推荐做系统盘           |
| **顺序读写速度**    | 大文件传输速度                   | 读≥5000MB/s，写≥4000MB/s为合格                     |
| **4K随机读写**      | 日常体验（开机/加载）的关键      | 看IOPS数值，>500K IOPS为优秀                       |
| **容量**            | 存储空间                         | 系统盘≥1TB；AI模型盘按需加                         |
| **TBW（写入寿命）** | 总写入量保证                     | 1TB TLC通常600–1200 TBW，够用5–10年                |
| **有无DRAM缓存**    | 影响持续写入和随机性能           | 有DRAM更好；无DRAM靠HMB模拟，日常够用              |
| **发热**            | 影响是否需要散热马甲             | PCIe 4.0建议贴主板自带散热片；PCIe 5.0必须主动散热 |

### 5.4 容量规划

| 用途                       | 预估占用                |
| -------------------------- | ----------------------- |
| Windows 11 + 常用软件      | ~80GB                   |
| 三角洲行动 + 无畏契约      | ~120GB                  |
| AI模型（7B/14B/32B各一个） | ~60–80GB                |
| 其他游戏/文件              | ~200GB                  |
| **合计**                   | **~500GB，1TB留有余量** |

## 六、电源：长城 G10 1000W 金牌全模组 ATX3.0

### 6.1 选了什么

**长城 猎金部落 G10 1000W**，80Plus金牌认证，全模组设计，ATX 3.0规范（自带12VHPWR线材），10年质保。价格约 ¥450–550。

> 若追求更稳：海韵 FOCUS GX-1000（¥650–750）或振华 LEADEX III 1000W（¥600–700）。

### 6.2 为什么选它

| 理由                | 说明                                                         |
| ------------------- | ------------------------------------------------------------ |
| **1000W为双卡铺路** | 单卡3090（350W）+7500F（65W）+其他≈465W，750W够用；但未来双卡3090=700W+，必须1000W |
| **金牌效率**        | 50%负载效率≥90%，省电且发热低。白牌/铜牌太丐，白金/钛金溢价不值 |
| **全模组**          | 所有线材可拆卸，按需接线，理线清爽，风道不被多余线材阻挡     |
| **ATX 3.0**         | 自带12VHPWR接口，未来换50系/60系N卡不用转接线                |
| **电源不能省**      | 电源是唯一"坏了会带走其他硬件"的部件。杂牌电源炸了=3090+主板全报废 |

### 6.3 电源选购核心参数

| 参数              | 含义                   | 怎么看                                   |
| ----------------- | ---------------------- | ---------------------------------------- |
| **额定功率（W）** | 持续输出能力（非峰值） | 整机功耗÷0.7=最低额定功率；留30%余量     |
| **80Plus认证**    | 转换效率等级           | 白<铜<**金**<白金<钛金；金牌是性价比甜点 |
| **模组化**        | 线材是否可拆           | 全模组>半模组>非模组                     |
| **ATX规范版本**   | ATX 2.x vs ATX 3.0     | 3.0支持12VHPWR、更严格瞬态响应           |
| **12VHPWR接口**   | 新N卡供电标准          | 有最好，为未来50/60系显卡铺路            |
| **电容品质**      | 影响寿命和纹波         | 日系电容（尼吉康/红宝石）>台系>国产      |
| **质保年限**      | 厂家信心指标           | ≥7年合格，10年优秀                       |
| **保护机制**      | OVP/OCP/OPP/SCP/OTP    | 必须有全部五重保护                       |

### 6.4 功率计算公式

```
整机功耗 = CPU TDP + GPU TDP + 主板/内存/SSD/风扇（~50W）
推荐电源功率 = 整机功耗 ÷ 0.7（最佳效率区间50%–80%）

本配置：
  单卡：(65 + 350 + 50) ÷ 0.7 ≈ 665W → 选750W–850W
  双卡：(65 + 700 + 50) ÷ 0.7 ≈ 1165W → 选1200W
  折中：1000W（单卡宽裕，双卡勉强可用）
```

### 6.5 避坑红线

| ❌ 绝对不做        | 原因                                                    |
| ----------------- | ------------------------------------------------------- |
| 不买杂牌/虚标电源 | "额定500W"实际可能只有300W                              |
| 不买二手电源      | 电容老化无法判断，随时可能炸                            |
| 不省这¥200        | 一个¥300杂牌电源炸了，带走¥4,000显卡+¥800主板           |
| 不混用线材        | 3090必须用电源附带的独立PCIe 8pin线，每条从电源单独拉出 |

## 七、CPU散热：利民 AX120 R SE

### 7.1 选了什么

**利民 AX120 R SE**，单塔4热管风冷，120mm风扇，解热能力150W，高度155mm。价格约 ¥70。

### 7.2 为什么选它

| 理由                           | 说明                                            |
| ------------------------------ | ----------------------------------------------- |
| **7500F只有65W**               | 百元风冷绰绰有余，完全不需要水冷                |
| **未来换R7 9700X（105W）也够** | 150W解热能力覆盖AM5中端全系                     |
| **155mm高度兼容性好**          | 绝大多数ATX/M-ATX机箱限高≥160mm                 |
| **水冷完全没必要**             | 240水冷¥300+，对65W CPU是纯浪费；还增加漏液风险 |

### 7.3 CPU散热选购核心参数

| 参数                | 含义                      | 怎么看                                |
| ------------------- | ------------------------- | ------------------------------------- |
| **散热方式**        | 风冷 vs 水冷（AIO一体式） | ≤105W选风冷；≥150W或追求静音选水冷    |
| **解热能力（TDP）** | 散热器能压住多少W的CPU    | 必须≥CPU实际功耗，留20%余量           |
| **热管数量**        | 导热效率                  | 4热管=主流，6热管=高端风冷            |
| **风扇尺寸**        | 120mm/140mm               | 140mm同转速更静音，但要确认机箱兼容   |
| **高度**            | 风冷塔体高度              | 必须<机箱CPU散热限高（通常160–170mm） |
| **噪音**            | dB值                      | ≤30dB优秀；满载≤40dB可接受            |
| **扣具兼容性**      | 是否支持AM5/LGA1700       | 2026年买新散热器基本都附带AM5扣具     |

### 7.4 散热方案速查

| CPU功耗                 | 推荐方案             | 价格区间 |
| ----------------------- | -------------------- | -------- |
| ≤65W（7500F）           | 单塔4热管风冷        | ¥60–100  |
| 65–105W（7600X/9700X）  | 单塔6热管 / 双塔风冷 | ¥100–200 |
| 105–170W（9900X/9950X） | 双塔风冷 / 240水冷   | ¥200–400 |
| >170W（超频旗舰）       | 360水冷              | ¥400–800 |

### 7.5 显卡散热（3090专项注意）

3090发热350W，是整机最大热源：

- 买二手时优先选**三风扇非公版**（华硕TUF/微星SUPRIM/技嘉AORUS）
- 避免涡轮版（噪音大、温度高）
- 到手后**必须换硅脂+导热垫**（¥50–100），温度可降10℃
- 日常使用**Afterburner降压-50mV**，功耗降10%性能损失<3%

## 八、机箱：先马 朱雀 Air（Mesh网孔版）

### 8.1 选了什么

**先马 朱雀 Air**，ATX中塔机箱，Mesh网孔前面板，支持340mm+显卡，下置电源仓，支持360水冷（未来）。价格约 ¥180–220。

> 若预算宽裕：酷冷至尊 TD500 Mesh V2（¥300–380）或联力 Lancool 216（¥400–500），风道更优。

### 8.2 为什么选它

| 理由               | 说明                                                   |
| ------------------ | ------------------------------------------------------ |
| **Mesh网孔前面板** | 3090发热350W，必须保证前方进风量。玻璃前面板会闷到降频 |
| **显卡限长≥340mm** | 3090长310–336mm，必须留余量                            |
| **ATX中塔**        | 兼容ATX/M-ATX/ITX所有板型，未来换大板不用换机箱        |
| **下置电源仓**     | 电源独立隔仓，不影响显卡风道                           |
| **支持4+风扇位**   | 前进2–3 + 后出1 + 顶出1–2，构建完整风道                |
| **¥200价位**       | 极致性价比，不花冤枉钱在铁皮上                         |

### 8.3 机箱选购核心参数

| 参数            | 含义                     | 怎么看                                  |
| --------------- | ------------------------ | --------------------------------------- |
| **板型兼容**    | 能装多大的主板           | ATX中塔兼容所有；M-ATX机箱不能装ATX大板 |
| **显卡限长**    | 能装多长的显卡           | 必须>显卡实际长度+10mm余量              |
| **显卡限厚**    | 能装多厚的显卡           | 3090是3槽（~60mm），机箱必须支持        |
| **CPU散热限高** | 风冷塔体最大高度         | 必须>散热器高度（AX120=155mm）          |
| **电源仓长度**  | 能装多长的电源           | 1000W电源通常160–180mm，确认放得下      |
| **前面板材质**  | Mesh网孔 vs 玻璃 vs 塑料 | **Mesh必选**（散热）；玻璃好看但闷      |
| **风扇位数量**  | 能装几个风扇             | 前≥2 + 后≥1 + 顶≥1 = 最低4个            |
| **防尘网**      | 进风口/顶是否有磁吸防尘  | 有最好，减少清灰频率                    |
| **走线空间**    | 背板走线是否宽裕         | 背板空间≥20mm，理线不影响侧板合上       |
| **侧透**        | 是否钢化玻璃侧板         | 纯审美需求，不影响性能                  |

### 8.4 机箱风道设计（比散热器本身更重要）

```
        ┌─── 顶部出风（1–2个120/140mm）───┐
        │                                   │
  前进风 │    ┌──────┐     ┌──────┐         │ 后出风
（2–3个  ├──→│ GPU  │──→  │ CPU  │────────→│（1个120mm）
 120mm） │    │ 3090 │     │ 散热 │         │
        │    └──────┘     └──────┘         │
        │                                   │
        └─── 底部进风（电源仓隔离）────────┘

  原则：正压差（进风量 > 出风量），灰尘从缝隙排出而非吸入
```

### 8.5 机箱类型速查

| 类型                  | 体积 | 适合场景         | 你的选择         |
| --------------------- | ---- | ---------------- | ---------------- |
| ITX（<20L）           | 极小 | 便携/桌面摆件    | ❌ 3090塞不进     |
| M-ATX（20–35L）       | 紧凑 | 小板用户         | ⚠️ 可以但扩展受限 |
| **ATX中塔（35–50L）** | 标准 | **游戏/AI/升级** | ✅ **首选**       |
| 全塔（>50L）          | 巨大 | 工作站/多卡      | ❌ 太大没必要     |

## 九、装机顺序与注意事项

### 9.1 推荐装机顺序

```
① 机箱外：CPU装入主板 → 涂硅脂 → 装散热器 → 插内存 → 装M.2 SSD
② 装主板到机箱（对准铜柱，拧螺丝）
③ 装电源到机箱（下置电源仓）
④ 接线（主板24pin → CPU 8pin → 前置USB/音频 → 风扇）
⑤ 最后装显卡（插PCIe x16槽 + 拧固定螺丝 + 接供电线）
⑥ 开机进BIOS → 开启EXPO → 装系统 → 装驱动
```

> ⚠️ **别在机箱里装CPU散热器**，空间狭小容易拧断主板。

### 9.2 二手3090到手必做

```
① 拆侧板检查PCB：有无暗伤/腐蚀/焊点异常
② 更换硅脂+导热垫（¥50–100）
③ FurMark烤机20分钟，确认温度<85℃
④ OCCT显存压力测试10分钟，确认无花屏
⑤ 确认无问题后再装入机箱
⑥ Afterburner设置降压-50mV日常使用
```

### 9.3 供电线接法（3090专项）

```
❌ 错误：一条PCIe 8pin线分出的两个头同时插3090
   → 单条线承载上限300W，3090峰值450W会烧线

✅ 正确：每条8pin线从电源独立拉出
   → 3090需要2–3条独立的8pin PCIe供电线
   → 必须使用电源附带的线材，不要混用其他电源的线
```

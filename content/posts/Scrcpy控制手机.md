# Scrcpy 控制手机

> **下载地址**：[Genymobile/scrcpy](https://github.com/Genymobile/scrcpy)

## 第一步：进入解压后的文件夹

找到你解压出来的文件夹（比如 `scrcpy-win64-v4.1`），**双击进入文件夹内部**。
在文件夹地址栏（显示路径的地方）输入 `cmd` 并按回车，这样就能直接在此路径下打开命令行窗口（确保系统能找到 `adb.exe` 和 `scrcpy.exe`）。

## 第二步：USB 线连接（仅此一次，用来激活无线）

1. 用 USB 数据线把手机插到电脑上。

2. 手机弹出“允许 USB 调试吗？”，点击 **确定**。

3. 在刚才打开的黑色命令行窗口里，输入以下命令并回车（这将自动开启手机的无线调试端口）：

   ```cmd
   adb tcpip 5555
   ```

   如果看到提示 `restarting in TCP mode port: 5555`，说明端口已开启成功。

## 第三步：查询手机 IP 地址

拔掉手机上的 USB 数据线。
在手机上进入 **设置 → 关于手机 → 状态信息**（或直接搜索“IP地址”），查看当前连接 Wi-Fi 的 **IP 地址**（例如 `192.168.1.105`）。

## 第四步：通过 Wi-Fi 连接并启动

回到电脑上刚才打开的 cmd 命令行窗口（还是在 scrcpy 文件夹路径下），输入以下命令（把 `192.168.x.x` 换成你手机上查到的真实 IP）：

```cmd
scrcpy --tcpip=192.168.243.220
```

稍微等一两秒，手机屏幕就会直接投射到电脑上了，此时 USB 线已经完全拔掉，用的是纯 Wi-Fi 连接。

## 以后（第二次及之后）怎么连接？

只要**手机没有重启过**，以后每次想连 Wi-Fi 时，不需要再插 USB 线了，直接按以下两步操作：

1. 在解压的 scrcpy 文件夹里打开 cmd。

2. 直接输入命令连接 IP 并启动（把 IP 换成你手机的）：

   ```cmd
   scrcpy --tcpip=192.168.243.220
   ```

------

## 如果手机重启过，怎么办？

手机重启后，无线调试端口会默认关闭。你需要**重复第二步**（用 USB 线插一次，重新执行 `adb tcpip 5555`）来重新激活端口，之后又能继续用纯 Wi-Fi 了。

## 补充提醒

- **防火墙拦截**：如果 Windows 弹出防火墙提示，请点击“允许”。
- **找不到 `adb`**：确保你是**在解压后的文件夹内部**打开的 cmd，不要在桌面直接打开。
- **连接失败**：如果提示 `unable to connect`，请检查手机和电脑是否连接的是**同一个 Wi-Fi 网络**。
